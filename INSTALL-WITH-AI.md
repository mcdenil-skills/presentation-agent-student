# Установка одним промптом

Это рекомендуемый способ для новичка. Вам не нужно самостоятельно вводить команды в терминале.

## Что понадобится

- установленный **Claude Code** или **Codex** с доступом к локальным файлам и терминалу;
- интернет;
- 5–15 минут.

Обычный чат Claude или ChatGPT в браузере не подойдёт: он не умеет устанавливать файлы на ваш компьютер.

## Шаг 1. Откройте Claude Code или Codex

Создайте новую локальную задачу. Можно открыть любую безопасную рабочую папку: установщик сам создаст рядом отдельную папку `presentation-agent-student`.

## Шаг 2. Вставьте один промпт

Скопируйте весь текст ниже и отправьте его агенту:

```text
Установи мне Presentation Agent из публичного репозитория:
https://github.com/Ntmib/presentation-agent-student

Сделай установку сам через терминал. Не проси меня вручную вводить команды.

Правила безопасности:
1. Сначала определи операционную систему и проверь доступные инструменты.
2. Установи проект в новую отдельную папку presentation-agent-student. Не помещай его внутрь другого Git-репозитория.
3. Если папка с таким именем уже существует, ничего не удаляй и не перезаписывай. Проверь её и предложи безопасное продолжение.
4. Скачай репозиторий через git clone. Если Git недоступен, скачай ZIP с GitHub и распакуй его в новую папку.
5. После скачивания полностью прочитай AGENTS.md, INSTALL-WITH-AI.md, START-HERE.md и PRIVACY.md.
6. Подготовь локальные личные файлы из *.example.md. Существующие файлы не перезаписывай.
7. Базовый текстовый режим должен заработать даже без Python. Если найден Python 3.11 или новее, запусти подходящий установщик из репозитория и выполни проверку. Если Python нет, не устанавливай системные программы и не используй sudo без моего отдельного согласия — просто объясни, что останется недоступно.
8. Не подключай Google Drive, не проси API-ключи, не читай и не показывай значения секретов. Это настраивается отдельно только по моему желанию.
9. Не делай git push и не публикуй мои рабочие материалы.
10. В конце сообщи: куда установлен проект, что уже работает, что осталось необязательным и как открыть именно эту папку в новой задаче Claude Code или Codex.

После установки дай мне готовый следующий промпт для первого знакомства с системой.
```

## Шаг 3. Дождитесь отчёта

Агент должен сообщить четыре вещи:

1. полный путь к установленной папке;
2. готов ли базовый текстовый режим;
3. прошла ли проверка Python-инструментов;
4. какие необязательные функции пока не подключены.

Если агент просит пароль администратора, API-ключ или доступ ко всему Google Drive — остановите его. Для первого запуска это не требуется.

## Шаг 4. Откройте установленную папку

Создайте новую задачу в Claude Code или Codex и выберите папку `presentation-agent-student`, которую назвал установщик. Затем вставьте:

```text
Я здесь впервые. Прочитай AGENTS.md и START-HERE.md.
Проверь, что локальные шаблоны созданы, и проведи меня по первому запуску.
Задавай по одному простому вопросу и не придумывай факты за меня.
```

После этого можно написать:

```text
Соберём продающий вебинар с нуля.
```

или:

```text
Соберём записанный обучающий урок с нуля.
```

## Что устанавливается автоматически

- методология вебинаров и уроков;
- правила для Claude Code и Codex;
- роли аналитика, разработчика контента, разведчика и проверяющего;
- безопасные локальные шаблоны голоса, памяти, продукта, аудитории и кейсов;
- Python-инструменты, если на компьютере уже есть Python 3.11+.

## Что не подключается автоматически

- Google Drive и Google Slides;
- Pexels и OpenAI API;
- личные анкеты, кейсы и материалы;
- публикация на GitHub.

Это сделано специально: сначала система работает локально без секретов, а внешние сервисы подключаются позже осознанно.

## Если автоматическая установка не получилась

Скачайте проект по кнопке **Code → Download ZIP** на странице репозитория, распакуйте архив и откройте полученную папку в Claude Code или Codex. Для работы над текстами больше ничего устанавливать не нужно.

Ручная настройка инструментов и Google Slides описана в [INSTALL.md](INSTALL.md).
