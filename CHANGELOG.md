# Changelog

## 2026-08-25 — установка одним промптом

- Добавлен единый безопасный промпт для установки через Claude Code или Codex без ручных команд.
- Во все инструкции подставлена публичная ссылка `Ntmib/presentation-agent-student`.
- Google Drive, API-ключи, системные программы и публикация не подключаются установщиком без отдельного согласия владельца.

## 2026-08-25 — инструкция для ученика

- Добавлен `START-HERE.md`: первый запуск, полные маршруты вебинара и урока, готовые запросы и решение частых проблем.
- Персональные файлы переведены на схему `*.example.md` → локальная Git-игнорируемая копия.
- Установщик создаёт локальные файлы идемпотентно: повторный запуск не стирает данные владельца.
- После security review минимальный Python поднят до 3.11, зависимости обновлены и зафиксированы, добавлен Dependabot и явное предупреждение о широком Google Drive OAuth.

## 2026-08-25

- Первая ученическая редакция с чистой историей Git.
- Удалены уроки, транскрипты, личная память, кейсы, данные ЦА и настроенные Google ID.
- Добавлена развилка «проектный практикум / обзор механики».
- Добавлена программа урока в начале и зеркальный итог в финале.
- Проверка слайдов различает многострочный промпт и несколько CLI-команд.
- Загрузка локальных изображений повторяется при кратком сетевом обрыве.
