# Голос на слайдах

Главный источник персонального голоса - `SOUL.md`. Этот файл задаёт универсальные правила читаемости.

## Слайд звучит как речь

Текст должен читаться естественно вслух и одновременно быть понятным без спикера. Используйте целые предложения со связками «но», «потому что», «зато», «поэтому».

Плохо:

```text
Опыт. Качество. Результат.
```

Лучше:

```text
Опыт сам по себе не гарантирует результат.
Важно, может ли человек повторить нужное действие в своей ситуации.
```

## Плотность

- Одна мысль говорится один раз.
- Соседний слайд не пересказывает предыдущий другими словами.
- Метафора остаётся только тогда, когда объясняет сложное.
- Очевидное не разжёвывается тремя фразами.
- Заголовок несёт вывод, а не ярлык «Проблема» или «Решение».

## Простой язык для взрослого

Объясняйте новичку, но не разговаривайте с ним как с ребёнком. Технический термин получает перевод на бытовой язык в той же фразе.

## Конкретика

Цифры допустимы только с источником. Если подтверждения нет, используйте честное описание без выдуманной точности или плейсхолдер `[НУЖЕН ФАКТ]`.

## Запреты

- канцелярит: «в рамках», «посредством», «осуществляется»;
- пустой пафос;
- телеграфные обрубки вместо предложений;
- декоративные метафоры без пользы;
- искусственные обещания и неподтверждённые числа;
- длинные абзацы, которые не помещаются в выбранную раскладку.

## Разница речи и слайда

В устной речи допустимы паузы, повторы для акцента и разговорные слова из `SOUL.md`. На слайде оставляйте только то, что помогает понять и запомнить мысль.

## Проверка

1. Прочитайте текст вслух.
2. Уберите фразы, которые нельзя сказать естественно.
3. Проверьте, понятен ли слайд без контекста соседнего.
4. Сверьте лексику с `SOUL.md` и обезличенным банком голоса аудитории.
