# Собственный дизайн

Ученическая редакция не содержит чужих шаблонов, Google ID, палитр или изображений.

Чтобы включить режиссёр раскладок:

1. Возьмите презентацию, которую вы имеете право использовать.
2. Запустите `tools/converters/template_inventory.py`.
3. Сохраните библиотеку как `layout-library.json` в эту папку.
4. Добавьте `etalon_id` своей презентации и проверьте роли доноров.
5. Создайте `rhythm-pattern.json` с количеством слайдов и желаемой долей фото.
6. Проверьте результат на копии, затем измерьте `max_words` для каждой раскладки.

Эти два JSON-файла могут содержать ваши Google ID, поэтому они игнорируются Git и не входят в общую методологию.
