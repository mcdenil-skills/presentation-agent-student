# Presentation Agent - ученическая редакция

Локальный AI-агент, который ведёт от идеи до готового материала в двух режимах:

- продающий вебинар - помогает получить заявки, не выдумывая кейсы и цифры;
- записанный урок - помогает довести ученика до проверяемого навыка без продажи внутри занятия.

Репозиторий содержит только универсальную методологию, роли, пустые шаблоны памяти и инструменты. В нём нет чужих уроков, транскриптов, клиентских данных, личных кейсов, Google ID или токенов.

## Установка без команд — рекомендуемый способ

Откройте локальный Claude Code или Codex и вставьте один промпт:

```text
Установи мне Presentation Agent из публичного репозитория:
https://github.com/mcdenil-skills/presentation-agent-student

Сделай всё сам через терминал и не проси меня вручную вводить команды.
Установи проект в новую отдельную папку и ничего существующего не удаляй и не перезаписывай.
После скачивания прочитай AGENTS.md, INSTALL-WITH-AI.md, START-HERE.md и PRIVACY.md и следуй им.
Подготовь локальные файлы из *.example.md. Базовый текстовый режим настрой обязательно; Python-инструменты — только если уже есть Python 3.11+.
Не используй sudo, не подключай Google Drive, не проси API-ключи и не делай git push без моего отдельного согласия.
В конце проверь установку, назови полный путь к папке и дай мне следующий промпт для первого запуска.
```

Полная пошаговая версия и решение частых проблем: [INSTALL-WITH-AI.md](INSTALL-WITH-AI.md).

## Впервые здесь?

Начните с [START-HERE.md](START-HERE.md). Там простым языком показано:

- как установить проект одним промптом без ручных команд;
- как запустить агента;
- что подготовить до вебинара или урока;
- какой готовый запрос вставить;
- что агент сделает сам, а что нужно дать ему;
- как дойти от идеи до текста или готовой Google-презентации.

## Быстрый старт

1. Установите проект одним промптом из [INSTALL-WITH-AI.md](INSTALL-WITH-AI.md) или вручную по [INSTALL.md](INSTALL.md).
2. Откройте папку в Codex или Claude Code.
3. Напишите: «Я здесь впервые. Проведи меня по быстрому старту из START-HERE.md».
4. Затем напишите: «Соберём вебинар с нуля» или «Сделаем записанный урок».

Агент сначала соберёт бриф и остановится на согласование. Он не должен придумывать отсутствующие факты.

## Главные принципы

- Сначала аудитория и цель, потом структура и тексты.
- Один слайд - одна законченная мысль.
- Любая цифра и кейс имеют источник.
- Команды в уроке проверяются вживую до публикации.
- Вебинар ведёт к офферу, урок ведёт к умению. Эти механики не смешиваются.
- Перед Google Slides весь текст читается подряд, чтобы убрать повторы на стыках.

## Безопасность

Личные файлы и рабочие материалы исключены из Git. Перед публикацией прочитайте [PRIVACY.md](PRIVACY.md) и проверьте `git status`.
